! Twilight Movies' own ad-blocker rules, added to the big lists (tools/filters/lists.txt).
! Change this file on GitHub (the pencil, then Commit): the filters are made again and every box gets them
! within a day (or at once with "Look for a new version" in the app's menu).
!
! The rules are in Adblock Plus / uBlock Origin form. A "!" starts a comment. Examples:
!   ||ads.example.com^                     block everything from a host (and its subdomains)
!   ||example.com/ads/*$script             block scripts from an address that starts like this
!   ||popads.example^$third-party          only when another site loads it
!   kurdfilm.krd##.banner-ad               hide the boxes with class banner-ad on that site
!   ##.sponsored-film                      hide them on every site
!   @@||cdn.example.com^$script            never block this (when a list blocks something the site needs)
!   @@||example.com^$document              leave this site alone entirely
!
! When something that must work gets blocked, add an @@ rule here and a line to checks.txt.
